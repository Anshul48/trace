# Narration script for the paper video, "Checkable memory for agents" (78 seconds).
# Every sentence is taken from the paper (paper/checkable-memory-for-agents.pdf); some are shortened.
# Numbers are exactly as in the paper. The voice is synthetic; it reads digit strings as words.
# Each block below is one card of the video.
#
# CARD cover (story-1-cover.png):
Checkable memory for agents: an audit of what an agent-built memory store can honestly claim.
#
# CARD 1 problem (img-1-problem.png):
When coding agents write a system's code, run its experiments and also write the reports on those experiments, how does anyone know which of the reported results are true? The reports can agree with the code and both still be wrong.
#
# CARD 2 trace (img-2-trace.png):
The store holds 812,545 passages of text, split into 4 separate partitions called shards.
#
# CARD 3 audit (img-3-audit.png):
Every result written in digits carries a receipt: the file it came from, the hash of that file, and the line where the value sits.
#
# CARD 4 results (img-4-results.png):
One result held: routing scored 0.79 percent of rows on every shard and kept 0.9985 of the exact top ten. Several did not: search by meaning found fewer labelled sources than keyword search, 26 of 50 against 41 of 50.
#
# CARD 5 planted errors (img-5-planted-errors.png):
When we planted 18 errors in a copy of this paper, the automated check caught 10 and missed 8: it catches wrong values and misses wrong meanings.
#
# CARD 6 next (img-6-next.png):
Each failure points at a specific change. None of these exists in the evaluated system; each is a hypothesis that must pass the same gate.
