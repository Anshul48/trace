About

An open research prototype.

TRACE is a memory that sorts itself into groups as it grows, so a question has to wake only a small part of it, and every answer carries a record you can check. It is a research prototype by one small team, open source under Apache-2.0.

What it is, and is not

  • Is: an experiment in memory for AI systems that keeps its own order, searches only a small part per question, and shows where each answer came from.
  • Is not: a product, a keyword-search replacement, a service you can call today, or something checked by anyone outside our team. See the limits.

Licence and data

The code is Apache-2.0 (LICENSE). The library's passages are English Wikipedia text, under CC BY-SA 4.0: each record names its article, so you can credit it. The text encoder is all-MiniLM-L6-v2 (sentence-transformers). Data and model licences are listed in repro-20k/LICENSES-DATA-MODEL.md.

Where things are in the repository

Folder or fileWhat is in it
docs/This website (served by GitHub Pages), including the explorer, the films and status.json. Written from docs-src/ by tools/build_site.py.
docs/explorer/The explorer: 144 recorded searches and the in-browser record check.
freeze-src/The tested engine, 207 files, never edited after testing. tools/verify_freeze.py checks it.
receipts/The records of our runs: the qualification run, the earlier larger builds, the order measurement.
repro-20k/A small reproduction you can run on your own computer.
demo-app/, demo/The demo backend and a synthetic demo, with tests.
tools/Checks (verify_freeze.py, check_receipts.py, check_links.py), the site generator and the local launcher.
docs/README.mdThe index of the technical documents (architecture, scale and memory, benchmarks, code tour).

Get in touch

Found a mistake, or re-ran something? Open an issue on GitHub; a report that a number does not hold is the most useful kind. For a security problem, see SECURITY.md. To cite TRACE, use CITATION.cff (GitHub shows a “Cite this repository” button).
