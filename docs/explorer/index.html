      What this shows, and what it does not

      What this shows

      • Real searches, recorded. Each question was asked on a sealed library of 812,545 passages of English Wikipedia, and the answers are shown as they came back.
      • A checkable record for every result. Which article it came from, where in the article, and a fingerprint your browser can re-check.
      • A second opinion. The same question asked with exact search, so you can see how close the two lists are.
      • A measured result. On our 50 test searches, TRACE kept 0.9985 of exact search’s results while scoring 0.79% of the rows (about 127 times less scoring work). The checkable records matched on all claims we re-ran on the live service. No outside party has verified this yet.
        How the 50 test searches were made

        40 written questions plus 10 taken from passage openings. The 0.79% counts rows scored per search, measured on one of the library’s four sections, for the top 10 results.

      What it does not show

      • It is not live. This is a replay of real queries recorded on the sealed corpus. The public live service is switched off.
        Why it is off

        It failed a first test with many people at once. A later fix passed a local retest, but we are still keeping the public service off.

      • Keyword search did better on this test. On the 50 test searches, ordinary keyword search put the right source passage in its top ten for 82% of them. TRACE did for 52%. TRACE is for meaning-based search you can verify, not a replacement for keyword search.
        More detail

        Exact meaning-based search also got 52%, so the gap is meaning-based search versus keywords, not TRACE’s shortcut. On a stricter score that also rewards putting the right passage higher up, keyword search got 0.74 and TRACE 0.42. Keyword search also answered faster: 6 milliseconds, against 1.2 seconds for TRACE (88 milliseconds for exact meaning-based search).

      • No speed or memory claim. Serving TRACE’s index takes 2.28 GB, against 1.25 GB for exact search and 0.51 GB for keyword search.
      • Not a random sample. We wrote 144 everyday questions before asking, and kept every answer. The tab Weaker matches holds the 29 where the top results read less well.
      • Public benchmarks were not run. We did not test TRACE on the public search benchmarks researchers use (called BEIR), so this page says nothing about how it compares there.
      • The library is slightly short of its goal. It holds about 99.9 million tokens (99,891,846; a token is roughly a word piece). The planned 100-million-token gate was waived: it falls short by 108,154 tokens, which is short of the 100M target by 0.11%.

      About the library and this replay

      The library

      812,545 passages of English Wikipedia text, cut from articles into pieces of a few sentences. It holds about 99.9 million tokens. The planned 100-million-token gate was waived: it falls short by 108,154 tokens (0.11%).

      The library is split into 4 sections, and inside each section similar passages are grouped together. To answer a question, TRACE picks the groups most likely to hold the answer and scores only the passages inside them. Exact search scores every passage.

      The recordings

      Loading the recording details.

      The server returns the ranked passages, their closeness scores and the first part of each passage’s text. For the record view we read the full passage and its record fields (article ID, character span, licence, fingerprint) straight from the sealed library’s own files, read-only. Article titles come from the first line of each article in the library. The only thing we change is a tidy-up of wiki markup in the text on cards; the record view can show each passage exactly as stored.

      Passages are excerpts of Wikipedia, licensed CC BY-SA 4.0. The code is Apache-2.0: github.com/Anshul48/trace.

      TRACE Explorer is a static page: plain HTML, CSS and JavaScript, with no build step and no server behind it. Recorded on the sealed library on an Azure VM in India Central.
