      Keyword search wins this test REAL

      Same 50 searches, sealed library. TRACE is meaning-based search you can verify — not a replacement for keyword search. The gap below is meaning-search versus keywords: exact meaning-based search also got 52%.

      What this means

      • TRACE's shortcut works: it kept 0.9985 of exact search's top ten while scoring 0.79% of rows on one part (~127× less scoring work).
      • But on finding the right source passage, keywords win here — use the right tool for the job.
