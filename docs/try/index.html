Try it

Start with your browser. Nothing to install.

Five ways in, ordered by effort. The first two take under a minute. The last one is the one you cannot do yet, and we say so.

Tested so far: a 99.9M-token library (measured), 310M and 504.5M-token builds (earlier tests, by us), a 1.53B-token routing test (separate). The ladder, with every caveat.

1. Open the explorer

Working today

30 seconds. Nothing to install. A web browser is enough.

The explorer replays 144 real searches that TRACE answered on our own server. Pick a question, read the ten passages it returned, and see how they compare with a full exact search.

  1. Open the explorer and pick a question, or type your own. There is no live search, so your words are matched to the closest recorded question, and the page tells you which one it used.
  2. Read the ranked passages. Each card says which article it came from.
  3. Look at the panel “Same answer as exact search?”.

Open the explorer

This is a replay of recorded searches over a 99.9M-token library, not a live service.

2. Check a record yourself

Working today

20 seconds. In the explorer.

Every result carries a checkable record: the article it came from, where in the article, the licence, and a fingerprint (a short code worked out from the exact text; change one letter and it changes completely). Your browser recomputes the fingerprint from the text on the page.

  1. Open the explorer and open the record of any result (“See its checkable record”).
  2. Press Check the fingerprint in my browser.
  3. It should say it matches.

Open a record already expanded

What a match shows: the text you see is unchanged since the library was sealed. What it does not show: that the search was right, or that Wikipedia says the same today.

3. Run the explorer on your own computer

Working today

2 minutes. Needs Python 3 and git.

git clone https://github.com/Anshul48/trace.git
cd trace
./tools/run-trace.sh        # Windows: tools\run-trace.bat

It serves this site on your computer (no outside requests) and opens the explorer. It is the same replay as step 1, running locally.

4. Re-check the code and run the small reproduction

Working today Working today

2 to 10 minutes. Needs Python 3, git, and two small Python packages.

This confirms that the published code is byte for byte the code we tested (207 files), and runs the small reproduction at 20,000 tokens on your machine. It reproduces the method on a small slice. It does not reproduce the 99.9M-token result: that needs our corpus and billed cloud hardware.

5. Search the whole library yourself

Not built yet Not built yet

Not possible yet.

  • A public live service is switched off. It failed a first test with many people using it at once. A later fix passed a local retest, but we are keeping the public service off.
  • A download you run on your own computer is planned. It does not exist yet, so there is no size or hardware list to give.

What exists instead is the explorer replay (step 1) and our own server, which you cannot query.
