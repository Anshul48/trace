Reproduce the benchmark

A full 10M-token reproduction has three blockers:

  1. External corpus. The 10M dataset (docs-100m.jsonl plus embedding cache) does not ship with the source; only the 1.2 MB source tarball is published.
  2. VM guard. --profile vm exits unless the hostname is trace-build500.
  3. 1M local cap. On your own machine, --profile local runs at most 1M tokens.

What you can run anywhere is the small local path, e.g.:

bash runtime.sh tools/product_pilot.py --tokens 10000 --profile local \
  --source-root <extracted-seam12a-dir> --data-dir <your-data-dir> --out <out-dir> \
  --drain-attribution --drain-census --holon-descriptor-columnar --overrides-columnar \
  --descriptor-matrix-all --per-view-sharing --cold-scan-chunk 4096 --repair-columnar \
  --candidate-source hnsw --drain-bounded-k 32 --candidate-shadow-audit 8

See the reproduction guide for data formats and the exact recipe.
