Try it on your machine

git clone https://github.com/Anshul48/trace.git
cd trace
./tools/run-trace.sh   # serves docs/, opens the explorer

Python 3 only — no services, no containers. Windows: tools\run-trace.bat. The local path runs up to 1M tokens; the 10M map above is the staged freeze (why).
