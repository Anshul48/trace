TRACE: self-organizing memory for LLMs and agents

TRACE is a self-organizing memory database: a 10-million-token persistent memory for LLMs and agents, filing every arrival into schemas and deltas without rebuilding the index. New documents become searchable the moment they land; each question descends only the most promising branches.

What it does for you

Researchers: long-horizon agent memory you can cite, retrieval-at-scale experiments under matched work budgets, and cross-domain schema linking through an overlapping graph.

Developers: persistent memory beyond the context window, local-first and content-addressed — the Python package and the product_pilot CLI run the real engine in an isolated venv.
