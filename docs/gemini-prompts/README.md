# Manual Gemini prompts for the actual `38c66bef` stack

Integrated prompt set in `docs/gemini-prompts/`, superseding earlier drafts (preserved outside this repo,
not edited by this lane). Generation is **manual in the Gemini browser**:
paste one `COPY FROM HERE` block at a time (or work through
`GEMINI_BROWSER_PROMPTS.txt`), export PNG 16:9 ≈2560×1440 under the
suggested filename, and pair each PNG with its caption from `CAPTIONS.md`.

Grounding, hard rules (no numbers/text/charts inside images, one style
family, truthfulness constraints), and the prompt inventory are in
`REFERENCE.md`. No images were generated by API in this lane: the checked
API free-tier image quota was 0 (`429 RESOURCE_EXHAUSTED`, 2026-10-14);
authored SVG assets in the release trees remain the embedded figures
until these bitmaps exist.

Files: `REFERENCE.md`, `CAPTIONS.md`, `GEMINI_BROWSER_PROMPTS.txt`,
`prompt-01-trace-stack-hero.txt`, `prompt-02-trace-lifecycle.txt`,
`prompt-03-trace-serving-generations.txt`, `prompt-04-trace-evidence-chain.txt`,
`prompt-05-trace-small-repro.txt`, `prompt-06-anima-ecosystem.txt`.
