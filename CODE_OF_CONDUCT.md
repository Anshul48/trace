# Code of conduct

Be respectful, specific, and evidence-based. Harassment, personal attacks,
and bad-faith disruption are not welcome in issues, pull requests, or
discussions. Report conduct or security concerns privately to the
repository owner through GitHub (see SECURITY.md for vulnerabilities);
do not post private information or credentials in public threads.
Maintainers may moderate or remove content that violates this code.
