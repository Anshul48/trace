Run it

pip install -e .[c10m]
python demos/demo_c10m_narrow.py

Expected verdict: DEMO PASS: pinned C2-10M serving stack ran offline (6 synth docs, 3 queries, budgets M80-P100-A40). Linux/POSIX only (the pinned store uses fcntl locking).

What this does not show

Encoder stand-in: the shipped stack encodes with MiniLM-L6-v2 (weights + torch, not vendored); the demo uses a deterministic SHA-256 token-hash encoder. Scores and ranking here are NOT 10M measurements. The 10M evidence (frozen Narrow rung, BENCH10M lanes, store probes, campaign receipts) lives under benchmarks/evidence/ with its original denominators, units, and failures preserved.
