## Assignment rule

Assign only the Stage 1 packets first. Stage 2 packets can be prepared but
should be assigned after Stage 1 produces an evaluation boundary and relevant
current-state evidence. An assigned packet is copied into its own task
directory with base commit, input hashes, and any required authority amendments.
