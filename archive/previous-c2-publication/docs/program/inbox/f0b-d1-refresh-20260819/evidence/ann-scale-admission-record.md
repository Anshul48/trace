- **Trace-Lite / Trace relevance:** Evaluates vector indexing performance (LanceDB / IVF-PQ / HNSW) under scale pressure.
- **Why this is a real-world workload:** Operational validation of vector search throughput under high concurrency.
- **Known mismatch with target product:** Does not test text summarization, tree organization, or text retrieval quality; currently generated by a synthetic loop in `AnnScaleAdapter`.
