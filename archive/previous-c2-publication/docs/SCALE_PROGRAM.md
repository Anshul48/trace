# Trace Scale Program

This is the entry point for the cross-repository program that takes Trace from
its current Foundation work through real-data scale gates and, conditionally,
to a billion- or trillion-token memory substrate.

Read in this order:

1. [`SCALE_MASTER_PLAN.md`](SCALE_MASTER_PLAN.md)
2. [`SCALE_HARD_PROBLEMS.md`](SCALE_HARD_PROBLEMS.md)
3. [`SCALE_DECISION_REGISTER.md`](SCALE_DECISION_REGISTER.md)
4. [`SCALE_RESEARCH_BASIS.md`](SCALE_RESEARCH_BASIS.md)
5. [`SCALE_AGENT_WORK_CONTRACT.md`](SCALE_AGENT_WORK_CONTRACT.md)

Component responsibilities are recorded in the workspace-relative
[`trace-lite/docs/dev/SCALE_ROLE.md`](../../trace-lite/docs/dev/SCALE_ROLE.md)
and [`trace-bench/SCALE_EVIDENCE_PLAN.md`](../../trace-bench/SCALE_EVIDENCE_PLAN.md).

[`future-scale-roadmap.md`](future-scale-roadmap.md) remains the directional
precursor. The files above add an execution, decision, research, and evidence
program without replacing the canonical Spine/Cortex architecture documents.

The current Foundation implementation wave remains the active prerequisite.
These files deliberately do not inspect or restate unfinished handoffs. They
make no scale claim: every promotion requires a frozen implementation identity,
a separate verification session, a real-corpus manifest, and a human decision.
